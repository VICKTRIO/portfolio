# Ache Web Development - Personal Portfolio

A modern, responsive, and high-performance personal portfolio website built to showcase professional web applications, development services, and technical expertise.

## 🚀 Live Demo
Check out the live portfolio: [Netlify Live Site](https://acme-portfolio.netlify.app/)

## ✨ Features
* **Responsive Navigation & Branding:** Clean header featuring the Ache Web Development brand identity and smooth mobile-friendly navigation.
* **Featured Projects Showcase:** Highlights key real-world applications including the DevSpace Platform, EduManger, and the portfolio itself, complete with direct links to Live Demos and GitHub repositories.
* **Interactive Services Section:** Clearly details professional offerings ranging from Frontend Engineering and Backend Solutions to UI/UX Optimization.
* **Integrated Newsletter Form:** Fully optimized with Netlify forms for seamlessly capturing user subscriptions.
* **Dark/Light Mode Support:** Includes an interactive theme switcher and a smooth "Back to Top" navigation utility.

## 🛠️ Built With
* **HTML5** - Structuring the web pages.
* **CSS3** - Styling, responsive layouts, and animations.
* **JavaScript (ES6+)** - Dynamic interactivity, theme toggling, and scroll animations.
* **Netlify** - Hosting, deployment, and form management.
